# DECISIONS — архитектурные решения

1. **Каталог `decision-passport/`**. Рабочая папка содержит материалы диссертации (docx/pptx) — приложение живёт в подкаталоге, чтобы не смешивать код с документами.

2. **SQLite вместо PostgreSQL**. Локальный Postgres не гарантирован. Prisma-схема написана переносимо: **без Prisma-enum** (SQLite их не поддерживает) — все перечисления хранятся как `String`, а типобезопасность обеспечивают константы и zod-схемы в `lib/domain.ts`. Для перехода на Postgres достаточно сменить `provider` и `DATABASE_URL`.

3. **NextAuth v4 (Credentials, JWT)** — стабильная версия, полностью совместимая с App Router. Роль пользователя кладётся в JWT и в session; серверные мутации перепроверяют права через `lib/authz.ts`, а не доверяют UI.

4. **Мутации — через Server Actions** (`app/actions/*`), плюс выделенный route handler `POST /api/decisions/[id]/advance` (как требует ТЗ). Каждая мутация: проверка прав → изменение → запись `AuditEvent` в одной транзакции.

5. **Движок ворот `lib/gates.ts` — чистые функции** над снимком решения (decision + блоки + альтернативы + риски + допущения + поручения + показатели). Это позволяет покрыть все правила юнит-тестами без БД. Таблица `GateCheck` в БД — конфигурация применимости правил (какое правило блокирует переход между какими стадиями для какой критичности); сами проверки — код с кодами правил.

6. **Полнота блоков** считается на сервере из фактического содержимого (payload + связанные сущности), а не хранится «на веру»; поле `completeness` кэширует расчёт.

7. **ИИ без ключей**: `MockProvider` — детерминированные ответы, построенные из реальных данных решения (поиск пропущенных блоков, сверка показателей между источниками, ранжирование альтернатив по сумме взвешенных критериев). `ApiProvider` читает `AI_API_KEY`; при отсутствии ключа молча откатывается на mock. Ни один ответ ИИ не применяется без записи `AiSuggestion` и явного вердикта человека.

8. **Деньги только из введённых параметров**: `lib/effects.ts` возвращает либо результат, либо список отсутствующих параметров (`missing: string[]`). UI показывает «Недостаточно данных для расчёта: …». Никаких оценок по умолчанию; `attributionShare` = 0.5 применяется только к риск-эффекту и редактируется с обоснованием.

9. **Tailwind v3 + рукописные shadcn-компоненты** (`components/ui/*` в стиле shadcn: cva + tailwind-merge). CLI shadcn интерактивен и тянет лишнее; для строгого корпоративного стиля достаточно ~12 примитивов, написанных вручную.

10. **Демо-цифры** внутри решений помечены бейджем «демо-данные» (глобальный бейдж в шапке + пометки в карточках); публичные показатели компании — блок «данные интегрированного годового отчёта 2025» со ссылкой на источник.

11. **Пароль всех демо-аккаунтов** — `demo1234` (bcrypt-хэш в сидах). Вход одним кликом с карточки роли просто подставляет креды в Credentials provider.

12. **Индекс зрелости** — среднее нормированных KPI пилотной выборки, всегда с контекстом (размер выборки, период, перечень KPI, пометка «расчёт по данным пилота»); в коде нет пути, где индекс показывается без этого контекста.
